# HR Analytics Dashboard | Power BI

## Project Overview
An interactive HR analytics dashboard designed to analyze employee data, understand attrition patterns, and monitor key workforce metrics.

## Tools Used
- Power BI
- SQL
- Python
- Excel

## Key Features
- Employee overview and KPI tracking
- Department-wise attrition analysis
- Salary and tenure analysis
- Performance and workforce diversity insights
- Interactive filters and visualizations
